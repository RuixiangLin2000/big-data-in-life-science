# 术语表（Glossary）

## 中文内容（Chinese Content）

核心术语包括：

- **大数据（Big data）：** 规模、复杂性或产生速度超出传统流程能力的数据。
- **生物信息学（Bioinformatics）：** 存储、分析和解释生物数据的计算方法。
- **数据来源（Data provenance）：** 数据来源及其处理过程的完整记录。
- **元数据（Metadata）：** 描述数据来源、结构、单位和条件的信息。
- **组学（Omics）：** 对基因组、转录组、蛋白质组或代谢组等生物实体的大规模测量。
- **可复现性（Reproducibility）：** 使用相同数据和记录完整的计算过程获得一致结果的能力。

## 英文原文（Original English）

# Glossary

| Term | Definition |
|---|---|
| Big data | Data whose scale, complexity, or rate of generation requires methods beyond conventional processing workflows. |
| Bioinformatics | Computational methods for storing, analyzing, and interpreting biological data. |
| Data provenance | A record of where data came from and how it was transformed. |
| Metadata | Information describing a dataset, including its origin, structure, units, and conditions. |
| Omics | Large-scale measurement of biological entities, such as genomes, transcripts, proteins, or metabolites. |
| Reproducibility | The ability to obtain consistent results using the same data and documented computational procedure. |
