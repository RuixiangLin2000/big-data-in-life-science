# 学习资源（Resources）

## 中文内容（Chinese Content）

本页用于记录权威学习材料。

添加数据集时，应记录来源、许可、访问日期和版本；添加软件时，应记录官方文档、版本、用途和安装说明；添加论文和书籍时，应提供完整引文，并说明其学习价值。

外部资源至少应记录作者或机构、标题、年份、持久链接或 DOI、网页访问日期，以及相关许可或使用限制。

---

## 英文原文（Original English）

# Resources

Use this page to record authoritative learning materials.

## Datasets

- Add course datasets with source, license, access date, and version.

## Software

- Add tools with official documentation, version, purpose, and installation notes.

## Papers and books

- Add complete citations and a short note explaining why each source is useful.

## Citation checklist

For every external resource, record:

- Author or organization
- Title
- Publication year
- Persistent URL or DOI
- Access date for web resources
- License or usage restrictions when relevant
